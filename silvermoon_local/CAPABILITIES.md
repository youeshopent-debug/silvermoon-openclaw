# 银月能力清单

## ✅ 已配置（直接可用）

| 能力 | 工具/方式 | 说明 |
|------|-----------|------|
| 上网搜索 | Tavily Search | 实时搜索互联网信息，调用 webSearch |
| 浏览网页 | browseWeb | 访问链接、读取页面文本内容（走代理） |
| 爬取网站 | Crawlee (PlaywrightCrawler) | 爬取完整页面内容，包括 JS 渲染的页面，自动处理反爬 |
| 登录网站 | Zero Token Auth | 用 Chrome 持久配置登录后，可访问需要登录的网站（1688/速卖通等） |
| 截图 | Puppeteer | 主人给网址，截图后直接发到对话 |
| 看图 | llava (本地) | 主人发图片，自动描述图片内容 |
| 下载文件 | downloadFile | 从互联网下载任何文件到本地磁盘 |
| 说话 | edge-tts | 文字转语音，发送语音消息到 Telegram |
| 语音转写 | STT (Zero Token / OpenAI) | 主人发语音消息，自动转写成文字 |
| 查汇率/金价/BTC/天气 | 内置查询 | 无需联网，本地计算 |
| 搜索记忆 | 短时/长时记忆 | 自动检索历史对话 |
| 生成文案/代码 | LLM 自身能力 | 无需额外工具 |
| 设置提醒 | 定时任务 | 通过 cron 调度 |
| 发送定时消息 | cron 任务 | 每日夜报等 |

## 🚫 银月做不到的事

- 操作主人的电脑桌面（无远程桌面权限）
- 直接修改 Telegram/Discord 服务器设置
- 执行任意系统命令（仅限白名单命令）
