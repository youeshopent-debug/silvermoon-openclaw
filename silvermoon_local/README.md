# 银月钱庄 · 本地配置副本

> 银月网关的本地运行配置与数据副本，用于离线调试与灾备恢复。

---

## 用途

- **离线调试**：在本地环境独立运行银月，不依赖主网关
- **配置备份**：`openclaw.env` 等敏感配置的本地副本
- **数据隔离**：`user_data/` 目录存放本地用户数据

## 目录结构

```
silvermoon_local/
├── silvermoon/
│   ├── main.js           # 银月本地实例入口
│   ├── openclaw.env      # 本地环境变量（含 DISCORD_TOKEN 等）
│   └── user_data/        # 本地用户数据
└── README.md
```

## 使用场景

1. **主网关宕机时**：切换到本地实例继续服务
2. **开发测试时**：在本地环境调试新功能
3. **配置迁移时**：作为配置模板参考

## 注意

- `openclaw.env` 包含敏感密钥，**不要**提交到公共仓库
- 本地实例与主网关共享同一份 `sects/` Agent 配置
