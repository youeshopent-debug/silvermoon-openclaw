> **项目**: 银月钱庄 ControlCenter
> **页面**: `/cultivation` — 修炼场 / Agent 可视化工作台
> **状态**: v2 像素办公室 → v3 现代化
> **PM**: 银月总管

---

## 1. 用户反馈分析：丑在哪里

| 问题 | 根因 | 影响程度 |
|------|------|---------|
| 像素风显得廉价 | Canvas 像素渲染 + 暗紫脏色 (#0f0d1a) 像未完工的独立游戏 | ★★★★★ |
| 与主控台视觉割裂 | index.html 是 Inter + 00D4FF 现代科技风，cultivation 是 Courier New + 像素字体 | ★★★★★ |
| 信息密度低 | 1280x720 固定画布只展示了 Agent 位置和状态，没展示任何运行指标 | ★★★★☆ |
| 交互笨重 | Canvas 纯渲染，hover tooltip 是唯一交互，无法点击展开详情 / 筛选 / 排序 | ★★★★☆ |
| 区域划分模糊 | 工作区/休息区/异常区用虚线框区分，视觉效果像 debug 辅助线 | ★★★☆☆ |
| 入口/墙壁无意义 | 占用了 30% 的显示面积，却没有承载任何信息 | ★★★☆☆ |
| 自适应差 | 1280x720 固定尺寸，宽屏或小屏体验极差 | ★★★☆☆ |
| 色彩浑浊 | 紫色基调 + 低对比度文字，可读性差 | ★★★☆☆ |

---

## 2. 重新设计的目标

1. **视觉对齐** → 与 index.html 主控台风格统一（深色科技风 #0A0A0A / #00D4FF / 818CF8）
2. **信息密度提升** → 一屏内可同时感知「Agent 位置 + 状态 + 关键指标」
3. **交互完整** → 可点击/筛选/搜索/排序，不再是纯观赏
4. **状态实时性** → 清晰展示 17 个 Agent 的心跳、最近活动、运行时长
5. **自适应** → 从 1366px 到 4K 屏均能良好展示
6. **可维护性** → 弃用 Canvas 像素渲染，改用标准 HTML/CSS/JS + SVG

## 3. 视觉方向建议

### 3.1 整体风格：Hybrid Dashboard (控件台 + 拓扑图)

吸取 GitHub Stars 页面的信息密度 + Grafana 的实时监控感 + 主控台的品牌体系。

### 3.2 配色方案（沿用 index.html 设计Token）

```
--bg-deep: #0A0A0A        (背景)
--bg-surface: #0D1117     (面板底色)
--bg-card: #161B22        (卡片底色)
--bg-elevated: #1C2128    (悬停高亮)
--accent: #00D4FF          (关键色/OC)
--secondary: #818CF8       (次要色/TR)
--cc-color: #CC44FF        (CC/曹操)
--success: #22C55E         (在线)
--warning: #F59E0B         (繁忙)
--error: #EF4444           (异常)
--text-primary: #F1F5F9
--text-secondary: #A1A1AA
--text-tertiary: #52525B
```

### 3.3 字体

- 标题/正文: **Inter** (与主控台一致)
- 状态/数字: **JetBrains Mono** (与主控台一致)

### 3.4 布局方案对比

| 方案 | 描述 | 优点 | 缺点 |
|------|------|------|------|
| **A. 星空拓扑图** (推荐) | 圆形/网格布局，每个 Agent 是一个发光节点，连线表示通信关系 | 科技感最强，适合展示 17 个 Agent | 开发复杂度高，需要 D3.js 或 Three.js |
| **B. 卡片矩阵** (中策) | 3列 x 6行 卡片网格，每张卡片对应一个 Agent | 开发简单，信息密度高，与 index.html Agent 网格统一 | 缺乏空间感和趣味性 |
| **C. 混合布局** (上策) | 上 1/3 是实时状态仪表盘 + 下 2/3 是拓扑图或空间分布 | 兼顾信息密度与视觉冲击 | 需要精心排版避免割裂 |

**推荐方案 C (混合布局)** — 详见图文说明。

## 7. 技术约束

| 项目 | 说明 |
|------|------|
| 渲染方式 | **纯 HTML/CSS/JS**，禁用 Canvas 像素渲染 |
| API 端点 | `/api/status` (现有), `/api/heartbeats` (现有) |
| 刷新频率 | 5 秒轮询 (现有) |
| 降级方案 | API 不可用时自动 fallback 到演示数据 (现有) |
| 状态映射 | `connected=true + lastHeartbeatAt<70s` = 在线; `connected=true + lastHeartbeatAt>=70s` = 挂机; `lastReason=error` = 异常; 其他 = 离线 |
| 视觉框架 | 沿用 index.html 的 CSS 变量体系，复用现有组件样式 |
| 代理/网络 | 外网请求走 `127.0.0.1:7890` |
| 浏览器兼容 | Chrome 最新版，可依赖 CSS Grid/Flexbox/backdrop-filter |
