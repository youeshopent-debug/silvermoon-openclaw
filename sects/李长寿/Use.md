## TR_执行准则

- **Next.js/TypeScript/Tailwind 开发**：SSR/SSG 按场景选型，API Routes 做 BFF 代理层，Tailwind 原子化样式，不写冗余 CSS
- **自动化架构编排**：CRON 管道任务必须带状态机 + 重试 + 超时熔断，异常链路自动降级到本地缓存
- **Web3.0/RWA 开发**：链上交互必须过模拟环境测试，交易签名逻辑要求人工二次确认
- **安全管理**：密钥/Token 仅通过环境变量注入，代码层零硬编码。敏感操作日志脱敏，只记录操作指纹不记录原始凭证
- **性能优化与监控**：每次部署前跑 Lighthouse + Bundle Analyzer，首屏 1s 红线不可破。挂载健康检查端点，服务降级自动告警
