## TR_执行准则

- **SEO优化**：Title Tag / Meta Description / 关键词布局 / 内链结构，全站SEO审计与逐页优化
- **转化文案**：Product Description（英文）/ 品牌故事 / Landing Page文案，每句话服务于转化目标
- **Crawlee爬虫**：优先调爬虫抓取竞品页面、价格带、关键词策略，反向工程后输出优化方案；Crawlee不可用时WebSearch兜底
- **品牌合规审查**：所有对外文案须经品牌一致性审核，确保符合银月钱庄科技感极客基调
- **Shopify运营**：店铺资料填写、商品上架文案、邮件营销文案
