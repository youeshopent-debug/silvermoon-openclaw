## 项目背景

银月钱庄目前有一个控制台（`localhost:4310`），功能是对的但视觉一塌糊涂——纯 Node.js 拼的 HTML 表格，没有任何设计可言。需要你出设计稿，我（李长寿）来实现。

## 品牌继承

**直接复用你之前定好的 MASTER.md 设计系统**，不要另起炉灶：
- 暗色 Neo-Minimalism + Glassmorphism
- 品牌色 `#00D4FF`（月光辉）

- 字体 Geist / Inter / JetBrains Mono

## 需要设计的页面（Frame）

### Frame 1：总览首页 / Overview Dashboard
**核心数据展示区，一屏看完全局**：
- 顶部导航条：Logo + 时间 + Agent 在线总数 + 系统状态徽章
- Agent 舰队总览：16 个 Agent 的网格卡片，每张显示名字、状态（在线/离线/忙碌/故障）、心跳时间
  - 状态用语义色圆点：绿 #22C55E / 黄 #F59E0B / 红 #EF4444 / 灰 #52525B
  - 卡片 hover 上浮效果
- 系统健康面板：CPU / 内存 / 运行时间
- 快速统计条：总任务 / 本月 Token 消耗 / 在线率

### Frame 2：Agent 详情 / Agent Detail
**点击某个 Agent 卡片后的详情页**：
- 顶部返回按钮 + Agent 名字 + 状态徽章
- Agent 档案卡片：ID / 席位 / 专业领域 / 隶属（OC/TR）
- 实时活动时间线：最近任务、心跳记录、消息历史
- 快捷操作按钮：查看日志 / 重启 / 发送指令

### Frame 3：任务管道 / Pipeline
**CRON 任务和自动化流水线的监控面板**：
- 管道列表：卡片式展示每个 CRON 任务（名称、调度Cron表达式、上次执行、下次执行、状态）
- 执行历史时间线
- 执行统计（成功数/失败数/平均耗时）
- 每个管道可手动触发执行

### Frame 4：系统日志 / Logs
**日志查看器**：
- 实时日志流（滚动）
- 过滤条件：级别（INFO/WARN/ERROR）/ Agent / 时间范围
- 日志级别颜色区分
- 搜索 / 清空

### Frame 5：Token 用量 / Usage
**Token 消耗监控**：
- 总用量仪表盘（本月、本周、今日）
- 按 Agent 拆分的消耗柱状图
- 按日期拆分的趋势折线图
- 剩余预算条

## 设计规范要求

1. **布局**：左侧固定导航 + 右侧主内容区（参考 Vercel Dashboard / Linear 布局）
2. **导航项**：Overview / Agents / Pipelines / Logs / Usage
3. **全局**：右上角放时间 + 系统状态
4. **动效**：
   - 页面切换淡入
   - 卡片 hover 上浮 + 发光
   - 数据加载 skeleton 占位
   - 状态切换流畅过渡
5. **响应式**：至少做到 1280px+ 桌面完美，1024px 可用
