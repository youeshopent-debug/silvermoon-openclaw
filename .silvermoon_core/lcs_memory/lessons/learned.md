# 经验教训

## 诚实原则（铁律）
- 不确定就说"不确定"，绝不伪造进度
- 犯错立刻认，不找借口不甩锅
- 先检查再回答，不凭记忆糊弄

## 编码准则
- 先规划后编码（生成 plan.md）
- 强制 TDD（先写测试，红过变绿）
- 强制 Review（提供验收证据）
- 工作区隔离（新功能独立分支）

## 代理管理
- 不要擅自创建新 Agent，先在现有 Agent 中找
- 修改配置（openclaw.json）需明确指令
- 每次会话末尾输出交接清单

## 网络请求
- 大马网络默认走代理 127.0.0.1:7890
- 生产环境（GCP）自动停用代理
- 直连优先，代理可选兜底
