## 修改文件

### 1. `lib/telegram-bridge.js`
- update_id 断点续传：saveUpdateId() + loadUpdateId()，Bot 重启时传入 offset 避免丢消息
- 级联重连兜底：_pollRetries >= 3 触发 restartAllBots() 全量重启
- healthCheck()：通过 bot.getMe() 每 60 秒主动探活 polling 状态
- restartAllBots()：优雅停所有 Bot 后按序重启
- Agent Bot 级联：连续 3 次失败同样触发全量重启
- 每条消息处理时持久化 update_id

### 2. `main.js`
- 全局 error handler：process.on('unhandledRejection') 和 process.on('uncaughtException') 不再 exit，改为写 crash.log + 触发 restartAllBots
- shortMemory 磁盘持久化：persistShortMemory() 每次 push 后同步写入 logs/short-memory.json
- shortMemory 启动加载：loadShortMemoryFromDisk() 在 memory.init() 前调用
- 健康监控定时器：每 60 秒调用 healthCheck()，失败则触发自愈
- 全局引用注册：global.__telegramBridge = telegramBridge

### 3. `scripts/_qa_verify_persistence.cjs` (新增)
可重复运行的 QA 验证脚本，验证 5 项核心能力

## 三层防御体系

| 层级 | 机制 | 文件 |
|------|------|------|
| 进程韧性 | 不exit()+优雅降级+自动重启 | main.js |
| 会话持久化 | shortMemory磁盘持久化+update_id断点续传 | main.js + telegram-bridge.js |
| 连接健康 | polling健康监控+主动探活+级联重连 | telegram-bridge.js |
