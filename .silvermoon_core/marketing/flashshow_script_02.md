## 2. 闪剪 (FlashShow) 配置参数

| 参数 | 设置 |
|------|------|
| **数字人形象** | 科技极客风 — 黑色高领毛衣或深色连帽衫 + 极简金属配饰（无多余装饰） |
| **数字人位置** | 0-3s: 不在画面（纯 POV）<br>3-8s: 右侧 30% 入镜<br>8-15s: 右下角小窗 20%<br>15-22s: 不在画面（纯演示）<br>22-28s: 居中 100% |
| **配音音色** | 年轻自信美式英语男声，偏中低音域，带一丝温暖感<br>建议：FlashShow 选 "Tech Founder / Startup" 风格 |
| **语速** | 比正常快 15% — 保持节奏感，但不至于听不清 |
| **背景音乐** | Tech/Phonk 风格纯器乐<br>选择方案：<br>— 0-8s: 低音量环境音 → 鼓点淡入<br>— 8-22s: 节奏鼓点（-18dB 人声优先）<br>— 22-28s: 和弦收束（-20dB） |
| **字幕样式** | Alex Hormozi 弹跳式动态字幕<br>— 关键词使用品牌蓝 **#00D4FF** 高亮<br>— 白色次要文字<br>— 每段不超过 6 个单词 |
| **画面过渡** | 快速剪切（每 2-3s 一切），无淡入淡出 |
| **色彩滤镜** | 轻微冷色调（青蓝倾向），高对比度，暗角晕影（营造沉浸感） |

## 4. 脚本策略说明 (为什么这样设计)

### 4.1 与第一弹脚本 (flashshow_script_01.md) 的差异化

| 维度 | 第一弹 (旧) | 第二弹 (本次) |
|------|-----------|------------|
| 品牌 | AIGenie Vision (泛品牌) | BWXKOEN Pro (精准 SKU) |
| 钩子 | "Stop using Google Translate" | "Stop scrolling if lost in a foreign country" |
| 框架 | 功能罗列型 | Problem/Solution Visual (2026 最高转化) |
| 视觉 | 单线叙事 | POV 第一人称 + 快节奏场景混剪 |
| 信任 | 基本参数说明 | 分屏对比 + 参数验证 + 风险逆转 |
| 定价 | 未提及 | $129.99 明确标价 + 免运费 |
| CTA | "Link in bio" 简单版 | 30天试用 + 免回寄运费 + 无手续费 |

### 4.2 市场依据

根据 2026 年 TikTok 广告数据分析：
- **Problem/Solution Visual** 是综合效果最好的钩子类型（评分 5/5）
- 63% 的爆款广告在前 3 秒内传达核心价值
- AI 翻译眼镜在美区 TikTok 正处爆发期（$60 竞品一周 GMV $23.45万）
- UGC 风格广告转化率比精修商业广告高 44%
- Spark Ads 完成率高 24%、互动率高 15%

### 4.3 心理触发设计

| 时间 | 心理触发 | 策略说明 |
|------|---------|---------|
| 0-3s | 自我投射 | "lost in foreign country" → 目标用户都经历过 |
| 3-8s | 好奇心+价格惊喜 | "Not $3,500" → 制造预期差 |
| 8-15s | 场景代入 | 3 个快场景覆盖 3 类用户痛点（旅行/商务/导航） |
| 15-22s | 理性验证 | 具体参数 + 社交证明 + 处方镜兼容解除顾虑 |
| 22-28s | 零风险承诺 | 30天试用 + 包退 → 消除最后决策阻力 |

## 5. A/B 测试变体建议

制作两个版本测试钩子效果：

**版本 A (推荐 — 硬钩):**
```
Hook: "Stop scrolling if you have ever felt completely lost in a foreign country."
→ 直接触发焦虑，转化速度更快
```

**版本 B (软钩 — 好奇心):**
```
Hook: "This $130 gadget replaced my phone in 6 countries. Here's how."
→ "数字钩 + 结果承诺"，适合冷启动测素材
```

### 测试指标

| 指标 | 合格线 | 优秀线 |
|------|-------|-------|
| Hook Rate (前 3s 留存) | > 30% | > 50% |
| 完播率 (Avg Watch Time) | > 8s | > 15s |
