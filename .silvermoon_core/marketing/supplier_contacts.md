## 一件代发对接方案

### 方案 A: LIGE 直发 (推荐, 即刻启动)

```
流程:
1. 注册 Alibaba.com 买家账号
2. 搜索 "LIGE BWXKOEN Pro Smart Glasses"
3. 选择 "Sample Order" (1件, $34.80)
4. 选择 Alibaba Trade Assurance 结算
5. 收货后验货 → 确认品质
6. 批量下单 → 直发 Shopify 客户地址
7. 若需品牌化: 联系 LIGE 谈 OEM (定制包装+Logo)

时间线:
- 样品: 3-5 天到货 (DHL/FedEx)
- 批量: 5-10 天 (Alibaba 海运/空运)
```

### 方案 B: LIGE + CJ Dropshipping 桥接

```
1. 在 CJ Dropshipping 搜索同款产品
2. 若 CJ 有库存 → Shopify 直接绑定 CJ 自动发货
3. 若 CJ 无此款 → 联系 CJ 买手代采 LIGE 产品
4. CJ 代采价 = LIGE 批发价 + 15-20% 服务费
   - 最终成本约 $41.76-43.56
   - Shopify 零售价 $129.99 → 毛利
