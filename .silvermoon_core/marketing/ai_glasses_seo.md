## 7. Technical SEO Checklist

### 7.1 Shopify 技术设置

- [ ] **自定义域名**: 配置 `silvermoon.bank`，启用 Cloudflare 代理（SSL + DDoS 防护）
- [ ] **robots.txt**: 允许所有搜索引擎爬取，屏蔽 `/cart`, `/account`, `/checkout` 等重复页面
- [ ] **sitemap.xml**: 确认 Shopify 自动生成的 sitemap 包含所有产品页/品类页/博客
- [ ] **canonical tags**: 确保无重复内容（特别是变体 SKU）
- [ ] **PageSpeed**: 移动端 LCP < 2.5s，FID < 100ms，CLS < 0.1
- [ ] **图片优化**: 全部 WebP 格式，产品图 ≤ 200KB，场景图 ≤ 300KB
- [ ] **AMP**: 博客内容启用 AMP（加速移动页）
- [ ] **结构化数据测试**: 通过 Google Rich Results Test 验证 FAQ Schema + Product Schema

### 7.2 Core Web Vitals 目标

| 指标 | 当前目标 | 优先级 |
|------|---------|--------|
| LCP (最大内容绘制) | < 2.5s | 🔴 高 |
| FID (首次输入延迟) | < 100ms | 🔴 高 |
| CLS (累计布局偏移) | < 0.1 | 🔴 高 |
| INP (交互到下一帧) | < 200ms | 🟡 中 |
| TTFB (首字节时间) | < 800ms | 🟡 中 |
